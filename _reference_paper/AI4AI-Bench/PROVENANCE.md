# AI4AI-Bench reference source

This directory is a local LaTeX reference copy of the AI4AI-Bench manuscript,
cloned from the authors' Overleaf project on 2026-08-20:

`https://git.overleaf.com/6a7c3f9c2ea1bc294ebd6886`

It is not part of the HL paper build. The copy preserves the manuscript source,
figures, tables, bibliography, style files, and build scripts while omitting the
source repository's `.git/`, generated `build/`, and generated `results/`
directories. It is retained because its paper organization and LaTeX layout are
useful references for the similarly structured HL paper.
