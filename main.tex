\abstract{We study continual learning in which nothing is learned in the weights.
A coding agent with a frozen base model is given an executable heuristic policy, a
game's rules, replays of the policy's own losses, and the authority to edit the
policy's source. What carries experience forward is neither a weight update nor an
accumulated prompt but the program itself: each revision is applied to the artifact
the previous revision produced, so the policy persists and accumulates across
rounds. The harness is fixed and there is no candidate population --- one artifact,
one revision per round, rescored against a frozen opponent pool --- which makes the
loop's limit a property of the artifact rather than of the search. We ask what that
limit is. The setting is \benchname, built from \val{ngames} games of a collegiate
game AI contest spanning editions \val{edfirst}--\val{edlast}, supplying
\val{nsubv} archived submission versions as a graded field of human-written
policies to be placed against. Improvement is not sustained: gains per revision
decay as \val{decay} and flatten near \val{plateau} revisions, while the program's
description length grows toward \val{maintcap} --- the size beyond which the agent
can no longer place an edit without disturbing behaviour that already works. Across
games of differing complexity that size converges within \val{maintcapspread}
while the strength reached there spreads by \val{eloplatspread}, so the ceiling
belongs to the maintainer and not to the game. Under a matched budget the same loop
also improves faster per unit of experience than model-based RL until
\val{crossover} environment steps, which locates the paradigm rather than
recommending it. What bounds policy-level continual learning is how much
executable structure an agent can keep coherent, not how much the task demands.}

\iffalse
\abstract{For decades a competitive game program was a symbolic construction,
bounded not by what it can express but by what a person will maintain: every new
case has to be reconciled with the rules already there.
Reinforcement learning (RL) displaced it by improving without an author at all.
Coding agents change who the author is, moving the operative property from
interpretability to editability, and we call the resulting paradigm
\emph{heuristic learning} (HL): an agent reads feedback and directly revises an
interpretable program --- here the rules, its own source, and replays of its
losses, rescored against a frozen opponent pool. We ask how far continued
maintenance goes once a machine pays its cost. The setting is \benchname, built
from the archive of a collegiate game AI contest spanning \val{editions} editions
since \val{founded}, whose \val{nsub} predominantly symbolic submissions and
\val{nmatch} matches supply a distribution of human skill rather than a single
reference. On
\val{nbeat} of \val{ngames} games an agent maintaining rules across \val{hlspan}
overtakes the strongest submission the archive records --- a program its authors
refined over \val{humanspan} of competition --- by \val{elogap} Elo, reaching the
\val{pct}th percentile of the field. Against RL in RL's own environments, an
agent-maintained policy wins on information per sample --- rules and a replay say
which decision lost a game, a scalar reward only that one was lost: it is \val{effratio} more sample-efficient than model-based RL at matched
Elo, holds within \val{robustspread} across seeds and games, and transfers to
\val{ntransfer} further benchmarks without retuning, until that baseline overtakes
it beyond \val{crossover} environment steps. Improvement then halts near
\val{plateau} revisions, for a reason that is a complexity one: HL succeeds while
the description length of a winning symbolic policy stays below the agent's
maintenance capacity, estimated after Kolmogorov complexity by compression. At the
plateau that length converges to \val{maintcap} within \val{maintcapspread} across
games of differing complexity while the Elo there spreads by
\val{eloplatspread} --- equal maintainable size at unequal strength, which makes
the ceiling the agent's and not the game's. What bounds the paradigm is the
description length of a winning program, not the complexity of the rules.}
